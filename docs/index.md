# se-cli Documentation

**Token-efficient Selenium browser automation for AI agents and humans.**

se-cli is a short-lived CLI + long-lived daemon that drives Chrome, Edge, and
Firefox. Compact aria snapshots with element refs keep token cost low, so your
agent can drive a real browser without burning context.
