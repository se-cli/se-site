# se-cli 文档

**面向 AI 智能体与人类的、节省 token 的 Selenium 浏览器自动化。**

se-cli 是一个短生命周期 CLI + 长生命周期守护进程，可驱动 Chrome、Edge 和 Firefox。
紧凑的 aria 快照配合元素引用（refs），让 token 消耗更低，你的智能体无需烧掉大量上下文即可驱动真实浏览器。
