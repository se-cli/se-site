Test Pages

Reference HTML pages used by the se-cli integration suite and browsable here for inspection. Each page is a standalone light-themed HTML file that resembles real-world pages you'd automate.

Quick start. Serve the site/ folder locally via python3 -m http.server 8000 --directory site, then drive a page with se-cli:
se-cli open http://localhost:8000/test-pages/forms.html

📝 Basics & Apps

  • Example Page
    A minimal page with one heading and one link — the canonical "first snapshot" target.
    test-pages/example.html
  • Todo App
    Interactive todo application — the full add / check / clear flow used in the acceptance criteria.
    test-pages/todo.html

✍️ Forms & Interaction

  • Form Elements
    Inputs, selects, checkboxes, and radios — exercises fill, select, check, uncheck.
    test-pages/forms.html
  • Button Test Page
    Buttons with click handlers — exercises click, dblclick, and hover state changes.
    test-pages/buttons.html

🧭 Navigation & Tabs

  • Navigation Links
    Links for testing goto, go-back, go-forward, and reload.
    test-pages/links.html
  • Tabs Test Page
    Links that open new tabs/windows — exercises tab-list, tab-new, tab-select, tab-close.
    test-pages/tabs.html

🎯 Snapshot & Structure

  • Snapshot Test Page
    Rich ARIA structure — nav, tabs, menu, tree, table, alerts — for snapshot and find testing.
    test-pages/snapshot.html
  • IFrame Test Page
    Same-origin and cross-origin iframes — exercises recursive snapshot with cross-frame refs (f3e15).
    test-pages/iframe.html
  • Shadow DOM Test Page
    Open shadow roots with interactive elements — exercises Shadow DOM traversal and ref assignment.
    test-pages/shadow-dom.html

💾 Storage

  • Storage Test Page
    localStorage and sessionStorage entries — exercises localstorage-*, sessionstorage-*, and state-save/load.
    test-pages/storage.html

🧪 Testing & Assertions

  • Wait & Retry Test Page
    Delayed visibility, dynamic elements, and flaky buttons — exercises --wait, --timeout, and --retry flags.
    test-pages/wait.html
  • Assertions Test Page
    Visibility, state, text, value, count, attribute, and dynamic elements — exercises expect assertions (v0.6).
    test-pages/assertions.html
  • Interactions Test Page
    Hover, drag, dialogs, upload, and resize targets — exercises v0.5 interaction commands.
    test-pages/interactions.html
  • Network Debug Test Page
    Console logs, network requests, and route mocking — exercises highlight, console, requests, route commands (v0.7).
    test-pages/network-debug.html
  • Emulation Probe
    Reports viewport, user agent, color scheme, timezone, locale, and touch — exercises device, emulate, and open-time emulation flags (v0.8).
    test-pages/emulation.html
Each test page is a standalone light-themed HTML file with its own inline styles — they intentionally differ from the documentation site so they resemble real-world pages you'd automate. The integration suite drives them with se-cli itself (dogfooding).
